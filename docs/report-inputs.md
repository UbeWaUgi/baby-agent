# 육아의나날 리포트 입력과 누락 처리

자동·즉시 리포트는 아이별로 **기록된 사실, 비교 가능한 범위, 보호자가 확인할 내용**을 보여준다. 식사·배변·수면·성장·사진과 영상은 각각 입력과 확인 범위가 다르다. 예를 들어 수유량을 모든 병 수유 기록에 입력했어도, 어린이집에 있던 시간의 수유 기록이 비어 있으면 하루 전체 섭취량은 확인할 수 없다.

## 기록에 추가할 항목

| 분야 | 기본 입력 | 해당할 때만 보충하는 입력 |
| --- | --- | --- |
| 수유·식사 | 발생 시각, 직접 모유수유·유축유·분유·이유식 등의 종류 | 양과 단위, 제공량·실제 섭취량·의미 미확인 구분, 실측·추정 구분. 직접 모유수유는 횟수와 기록된 시간을 사용한다. 식재료나 새 음식, 게워냄 등은 보호자가 필요할 때 기록한다. |
| 소변·대변 | 기저귀 교체나 배변 시각, 소변과 대변 각각의 있음·없음·미확인 | 젖은 기저귀 여부, 대변 색·굳기, 보호자 메모와 관련 사진. 한 교체에 소변과 대변이 모두 있으면 각 항목에 한 번씩 반영한다. 젖은 기저귀 교체 횟수는 해당 형태의 기록으로 표시한다. |
| 수면 | 잠든 시각, 깬 시각, 진행 중·종료 확인·종료 시각 미확인 상태 | 낮잠·밤잠 구분, 보호자가 입력한 중간에 깬 구간, 시각이 대략적인지 여부 |
| 성장 | 생년월일, 측정일, 측정 종류, 수치·단위 | 누운 길이·선 키의 구분, 집·병원 등 측정 출처, 기준표에 필요한 성별 정보. 교정월령은 필요한 자료가 있고 해당 기준에서 적용하는 경우에 사용한다. |
| 컨디션 | 보호자가 남긴 관찰과 관찰 시각 | 평소와 달라진 시점과 횟수, 더 확인하고 싶은 내용. 체온을 쟀을 때만 값·단위·측정 부위 또는 방식·시각을 받는다. |
| 사진·영상 | 아이, 촬영일시 또는 날짜만 확인된 상태, 원본 참조 | 연결한 육아 기록, 실제 분석한 프레임이나 영상 구간, 화질·가림 등 확인 범위, AI의 관찰 후보와 보호자의 확인·수정 상태 |

소변과 체중 기록은 특히 신생아 수유를 상담할 때 참고 자료가 될 수 있다. 아이의 섭취 상태는 수유 기록 외에도 성장과 여러 관찰을 함께 살펴야 한다. 배변은 나이와 먹는 음식에 따라 횟수와 상태가 달라질 수 있다. [CDC 신생아 수유 안내](https://www.cdc.gov/infant-toddler-nutrition/faqs/index.html) · [질병관리청 대변 이상](https://health.kdca.go.kr/healthinfo/biz/health/gnrlzHealthInfo/gnrlzHealthInfo/gnrlzHealthInfoView.do?cntnts_sn=5722)

체온은 측정 부위와 방식에 따라 해석이 달라질 수 있다. 성장곡선은 실측 기록과 기준표 판본을 연결하고, 측정이 한 번이면 해당 측정점을 보여준다. 추세는 비교 가능한 측정이 두 번 이상 있을 때 표시한다. [AAP 체온 측정 안내](https://www.healthychildren.org/English/health-issues/conditions/fever/Pages/How-to-Take-a-Childs-Temperature.aspx) · [질병관리청 성장도표](https://www.kdca.go.kr/kdca/5458/subview.do)

## 기록 범위와 값의 누락

리포트의 분야마다 아래 세 가지 정보를 따로 표시한다.

| 정보 | 저장할 내용 | 표시 예시 |
| --- | --- | --- |
| 자료 기준 시각 | 아이, 가족 시간대, 대상 날짜, 집계 시작·종료, 리포트가 사용한 데이터 버전 | 오늘 00:00~16:00 기준 |
| 기록 범위 | 분야, 시작·종료, 미확인·일부 확인·보호자 확인 상태, 출처. 보호자가 알려준 공백은 시간 구간으로 저장한다. | 13:00~16:00 어린이집 수유 자료 미확인 |
| 값 입력 현황 | 기록된 총 건수, 해당 값이 적용되는 건수, 값이 입력된 건수, 누락·의미 미확인 건수 | 병 수유 3회 중 2회 섭취량 기록 |

가져오기 파일의 조회 기간은 파일 출처 정보로 저장한다. 보호자가 실제로 기록한 시간 범위와 분야별 확인 상태는 따로 관리한다. 예를 들어 수면 기록을 하루치 확인했더라도 같은 날의 수유·소변 기록 범위는 각각 확인한다.

- **확인된 0**은 보호자가 해당 구간에 사건이 없었다고 확인한 값이다. 빈 입력은 미입력으로 표시한다. 이미 기록된 사건과 0회 확인이 충돌하면 확인할 항목으로 보여준다.
- **해당 없음**은 값을 적용할 수 없는 경우다. 직접 모유수유의 섭취 mL는 병 수유의 양 입력 현황에서 제외하고, 직접 수유 횟수와 기록된 시간을 함께 보여준다.
- **뜻이 확인되지 않은 수치**는 원 단위와 원본 필드명을 보존한다. 예를 들어 가져온 `120mL`가 제공량인지 실제 섭취량인지 알 수 없으면 개별 기록에 표시하고 섭취량 합계에서는 보류한다.
- 시간 정보는 **실제 발생 시각, 앱에 들어온 시각, 리포트 기준 시각**으로 나눠 저장한다. 날짜만 아는 사진이나 기록은 날짜 화면에 보여주고, 당일 16:00까지의 정밀 시각 비교에서는 별도 표시한다.

입력은 수유·배변·수면 시작/종료처럼 자주 쓰는 동작을 짧게 유지한다. **오늘 화면의 확인할 기록**에서 누락이나 모호한 항목을 모아 보여주고, 항목을 누르면 관련 기록을 수정할 수 있다. 의미를 확인하기 어려운 항목은 `모름`으로 남길 수 있다.

## 리포트 계산과 근거 연결

1. **가져온 기록과 수기 보완을 병합한다.** 같은 사건으로 확인된 기록은 한 건으로 집계한다. 중복 후보는 기존 확정 기록을 유지하면서 새 후보를 확인 대기로 표시한다. 가져온 값과 보호자 수정값을 모두 보존하고, 리포트는 확정된 값을 사용한다.
2. **수치를 집계한다.** 분유·유축유의 실제 섭취량, 직접 모유수유, 이유식은 구분한다. 실측과 추정값을 각각 표시한다. 수면은 서로 겹치는 확인된 구간을 합쳐 한 번만 계산하고, 자정과 리포트 종료 시각에서 잘라 집계한다. 수면 종료가 기록되지 않은 건은 진행 중 또는 종료 미확인으로 보여준다.
3. **비교 조건을 확인한다.** 즉시 리포트는 과거의 같은 시간대에 같은 방식으로 기록된 값과 비교한다. 비교에 사용한 기간과 날짜 수를 표시한다. 데이터 범위나 수유 방식이 달라 비교하기 어려우면 기록 합계와 그 이유를 표시한다. WHO 수면 참고 범위는 낮잠을 포함한 24시간 기준이므로, 기록 범위가 확인된 하루치에 표시한다. [WHO 영유아 수면 지침](https://www.who.int/publications/i/item/9789241550536)
4. **사진·영상과 공식 근거를 붙인다.** AI가 본 장면은 촬영일과 실제 분석 구간에 연결한다. 확인이 필요한 경우 보호자가 수정하거나 상담하고 싶은 내용으로 표시할 수 있다. 상담 안내는 보호자가 표시한 걱정, 실제 검진 결과, 또는 적용 조건이 맞는 의료진 검토 기준에 연결한다. 아이가 이전에 하던 행동을 잃었다는 보호자 기록처럼 상담에 의미 있는 내용은 일일 자료가 덜 모여도 안내를 표시할 수 있다. [CDC 발달 상담 안내](https://www.cdc.gov/act-early/milestones/)
5. **리포트 생성 시점과 갱신을 관리한다.** 자동 리포트는 늦게 들어온 기록이 속한 날짜와 영향을 받는 비교를 갱신한다. 즉시 리포트는 요청 당시 자료 기준 시각과 이력을 보여준다. 이후 갱신본이 필요하면 새 요청으로 생성한다. 미디어나 관찰을 삭제하면 기본 리포트와 이력에서 이를 인용한 문장과 썸네일도 함께 정리한다.

리포트 항목에는 **원본 기록 ID와 개정 번호, 사진·영상 ID와 구간, 적용한 지식과 규칙의 판본**을 남긴다. 앱이 계산한 수치와 누락 상태는 그대로 표시한다. AI 설명에는 해당 항목과 근거에 대한 연결을 붙인다.

## 화면 표시 예시

다음은 16:00에 만든 즉시 리포트의 가상 예시다.

| 리포트 항목 | 표시 내용 | 화면 동작 |
| --- | --- | --- |
| 수유 | 직접 모유수유 1회. 병 수유 3회 중 실제 섭취량을 기록한 2회 합계는 200mL. 나머지 1회는 제공량 120mL만 있어요. | 섭취량 확인 |
| 기록 범위 | 13:00~16:00 어린이집 수유 자료는 아직 확인되지 않았어요. | 기록 있는지 확인 |
| 배변 | 기저귀 교체 2회. 젖은 기저귀 1회 확인. 대변 여부 미확인 1회. | 기저귀 기록 열기 |
| 수면 | 확인된 수면은 16:00까지 7시간 35분이에요. 24시간의 기록 범위를 확인한 뒤 월령별 참고 범위를 표시해요. | 수면 기록 열기 |
| 영상 | 14:10 영상 00:08~00:13에 장난감을 손으로 집는 모습이 보여요. 보호자 확인 대기예요. | 해당 구간 재생 |

보호자가 수유량을 보완하면 자동 리포트의 해당 날짜 수유 집계와 이에 의존하는 비교를 갱신한다. 영상이 같으면 기존 분석을 다시 사용한다.

## 구현 확인 기준

- 직접 모유수유 1회와 병 수유 3회 중 실제 섭취량이 2건이면 `2/3건`과 실제 섭취량의 합계를 표시한다. 제공량만 있는 건과 직접 모유수유는 해당 합계에서 제외한다.
- 가져오기가 24시간 범위여도, 분야별 확인 상태가 없으면 집계를 `기록된 합계`로 표시한다.
- 소변과 대변이 모두 있는 기저귀 교체는 교체 1회, 소변 있음 1회, 대변 있음 1회로 처리한다. 빈 기록은 확인된 0과 다르게 표시한다.
- 23:40~00:20 수면은 각각 20분으로 계산하고, 중복 수면 구간을 두 번 더하지 않는다. 종료 미확인 구간은 확정 수면 시간과 구분한다.
- 오후 즉시 리포트는 24시간 지침과 직접 비교하지 않는다. 발생 시각이 같은 기록이라도 요청 뒤에 가져온 자료는 새 리포트에서 반영한다.
- 일부 영상 프레임으로 확인한 장면과 분석하지 않은 구간을 구분한다. 보호자 확인이나 검토 기준이 필요한 상담 안내에는 해당 근거 유형을 저장한다.
- 영상이나 보호자 관찰을 삭제하면 리포트 이력에 남아 있던 관련 설명과 썸네일도 열람할 수 없게 처리한다.

실제 BabyTime 내보내기 파일의 필드명·단위·제공량과 섭취량 구분은 샘플로 검증한다. 자동 상담 안내 기준은 의료진이 월령, 필수 정보, 표시 문구를 검토한 항목부터 활성화한다.
