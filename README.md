# 육아의나날

Kotlin과 Jetpack Compose로 만든 안드로이드 앱입니다. 기록은 기기 내부 Room DB에 저장하고, 사진 달력에 추가한 사진은 앱 내부에 저장합니다.

## 실행

Android Studio에서 프로젝트 폴더를 열고 JDK 17 이상과 Android SDK 36을 설정한 뒤 `app`을 실행하세요. 안드로이드 8.0(API 26) 이상을 지원합니다.

Windows에서 APK를 빌드하고 단위 테스트를 실행하려면 다음 명령을 사용합니다.

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest
```

디버그 APK는 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다.

## BabyTime 가져오기

1. 아이를 등록한 뒤 상단의 **가져오기**를 누르고 BabyTime에서 내보낸 TXT 또는 ZIP 파일을 선택합니다.
2. 아이 이름과 기록 기간을 확인합니다. 수기 기록과 비슷한 항목은 연결하거나 별도 기록으로 추가하거나 건너뛸 수 있습니다.
3. 가져온 과거 기록은 **하루 트랙**에서 날짜를 골라 확인합니다.

현재 파서는 공개 예시의 활동 구분선과 시각·유형 필드를 읽습니다. ZIP에서는 `activity_<아이 이름>_YYYYMM.txt` 기록을 사용하며 한 번에 한 아이의 자료를 가져옵니다. 제공량과 섭취량의 뜻이 모호한 수치는 합계와 구분해 보여줍니다. 현재 BabyTime 안드로이드 앱에서 사용자가 직접 내보낸 파일은 호환성 확인이 필요합니다. [참고한 공개 형식](https://cran.r-project.org/package=babyTimeR)

## 화면과 날짜 이동

- **홈**은 오늘의 기록과 수유·식사, 기저귀, 수면 빠른 입력을 보여줍니다.
- **하루 트랙**은 선택한 날짜의 기록을 24시간 축에 표시합니다. 기록을 선택해 확인하거나 수정할 수 있습니다.
- **사진 달력**에서 날짜를 선택하고 **사진 추가**로 휴대폰 사진을 선택하면 해당 날짜에 사진이 저장됩니다. 달력에서 삭제하면 앱에 저장한 복사본이 삭제됩니다.
- 하루 트랙이나 사진 달력의 **이날 리포트 보기**는 선택한 날짜를 그대로 엽니다. 저장된 리포트가 없는 날짜는 그날 기록을 요약해서 보여줍니다.
- **자동 리포트 설정**에서 목표 시각을 정합니다. 완료 알림을 받으려면 안드로이드 알림을 허용하세요. 배터리 상태와 시스템 설정에 따라 실행이 늦어질 수 있습니다.
- 오늘의 **즉시 리포트 만들기**는 요청 시각까지의 기록과 선택 입력한 보호자 메모를 저장합니다. 상세의 **PDF로 저장**은 그날 사진과 표시된 요약을 문서에 담습니다.

## 갤러리 자동 정리

1. **사진 달력 → 기준 사진 등록**에서 아이 얼굴이 선명하게 하나만 나온 사진을 고릅니다.
2. 안드로이드가 요청하는 사진·영상 접근 범위를 선택합니다. 일부 항목만 허용하면 그 범위 안에서 아이를 찾습니다.
3. **새 항목 자동 정리**를 켜면 기기 상태가 허용할 때 하루 단위로 새 항목을 찾아 정리합니다. **지금 정리**는 즉시 작업을 요청합니다.
4. 얼굴이 비슷하지만 확신하기 어려운 항목은 **확인할 사진·영상**에서 직접 확인할 수 있습니다.

앱은 기준 사진에서 추출한 얼굴 특징과 판정 기록을 기기에 저장합니다. 결과에는 갤러리 원본 주소를 사용하고, 같은 항목을 다시 열어 분석하는 대신 저장한 판정을 재사용합니다. 기준 사진을 바꾸거나 갤러리 항목이 수정되면 다시 비교합니다. 영상은 일부 장면의 얼굴을 비교합니다. 촬영 시각을 찾을 수 없으면 파일 날짜를 사용하고 화면에 표시합니다.

자동으로 모은 사진과 영상은 날짜별 리포트에서 열 수 있습니다. PDF에는 사진과 영상 개수가 들어가며, 영상은 앱 리포트에서 재생합니다.
